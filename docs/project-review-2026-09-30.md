# 项目功能与实际安全审查（2026-09-30）

审查以当前学校考试系统为实际使用范围，检查了前端路由和页面、后端鉴权和公开入口、花名册、考试生命周期、知识库和模板、成绩复核与分析、录制文件、配置与发布脚本。旧 HR、招聘及视频面试接口的外部访问继续被拒绝，其内部代码主要作为考试引擎及兼容数据实现检查。没有把需要管理员控制服务器、篡改数据库或极低概率竞态才能发生的情况列为安全漏洞。

## 修复结果

| 问题 | 实际触发和影响 | 修复及验证 |
| --- | --- | --- |
| 生产管理员公开默认密码 | 生产新安装或尚未修改默认密码的内置账号可被使用 `123456` 登录；强制改密并不能证明登录者是合法管理员 | `prod` 环境生成每个账号独立的强随机初始密码；已有默认密码被替换并撤销旧会话；已修改的密码保持不变。开发环境保留原行为。生产/开发/已有账号回归测试验证 |
| 隐藏成绩仍泄露平均分 | 关闭实时或最终成绩后，学生历史接口仍包含 `averageScore` | 隐藏全部成绩和总结字段；SQLite 服务测试和真实 HTTP 检查历史、流程、逐题记录及分析入口 |
| 停用花名册未阻断答题接口 | 已登录的学生在花名册或班级停用后，仍可直接调用考试引擎接口 | 所有学生执行入口检查当前花名册绑定和学生/班级状态；覆盖题目、提交、流式提交、心跳、记录、防作弊事件及跨学生访问，HTTP 测试确认停用/恢复行为 |
| 学生登记缺少限流 | 公开姓名/学号入口允许不断尝试 | 复用 Redis 限流；每个学号默认每分钟 10 次，共享 IP 默认每分钟 600 次。控制器拒绝路径测试与限流参数测试；整班共享 IP 的预算独立于学号预算 |
| 登记响应暴露 JWT | 登录 Cookie 是 HttpOnly，但登记响应同时包含脚本可读取的 JWT | 对外只返回用户信息，JWT 仅写 Cookie；真实 HTTP 并发测试改用 Cookie 认证并检查 HttpOnly |
| 退出全屏事件漏报 | 先清除“考试已开始”状态，随后上报被自身条件拦截 | 先记录事件再暂停；执行页面真实事件处理函数的回归测试在修复前失败、修复后通过 |
| 不及格成绩漏入班级统计 | `REJECTED` 是正常不及格结考状态，统计却只计算 `COMPLETED`，使均分偏高 | 将已完成和不及格结考都纳入统计，仍排除进行中的记录；真实数据库测试验证得分率、失分率和知识点 |
| 评分中断后无法恢复 | 处理租约过期的已保存回答不再出现在下一题接口；评分失败后刷新会丢失重试所需的原回答 | 返回过期租约题目供幂等重试，页面恢复并保护已保存回答、避免重复提交和换题残留；真实 HTTP 模拟中断并确认仅重算一次 |
| Excel 导入绕过字段长度限制 | 导入直接调用服务，跳过 HTTP DTO 校验；超长字段在 SQLite 被接受，在 PostgreSQL 可能使整批事务失败 | 在写入前检查同样的字段长度；测试坏行被拒绝、后续合法行仍成功 |
| 发布 JAR 的前端入口不可用 | 发布脚本明确嵌入前端，但默认拒绝策略拦截页面/资源，浏览器历史路由缺少回退 | 仅开放列出的 GET 页面和构建资源；增加 SPA 回退。MockMvc 及真实 HTTP 检查首页、深层页面、资源与受保护 API |
| systemd 安装后配置无法保存 | 服务用户拥有 `.env` 文件，但 root 所有的父目录不允许创建原子替换所需临时文件；站点设置也无法创建 | 将配置放入服务用户所有、权限 `0700` 的 `/opt/auto-hr/config`，环境文件 `0600`；启动和运行时编辑使用相同路径；迁移旧默认配置。Java 路径测试和 Bash 语法检查通过 |

## 验证与边界

- 原有后端完整测试及前端 13 项测试在修改前通过；新增隐藏分数、统计、停用及全屏测试明确复现原问题。
- 修改后完整 Maven 测试共 151 项，全部通过、无跳过。其中包含真实 HTTP、真实 SQLite、60 个学生两轮答题、网络幂等重试、成绩保密、停用、跨学生访问、过期评分恢复和嵌入前端路由检查。
- 前端 17 项测试及 Vite 生产构建通过；构建仍有原有的依赖注释和包体积提示。
- 外部 LLM 和 Redis 在并发测试中隔离替代。验证的是请求处理、持久化和权限行为，不是实际供应商表现或 Redis 服务部署。
- 本机未实际部署 Linux systemd，也未在本次审查中启动 PostgreSQL/MySQL；对应安装权限和 SQL 兼容性进行了代码检查。真实验证的数据库是 SQLite。浏览器摄像头/屏幕权限没有做人工设备测试。
- 生产内置账号仍使用默认密码的安装在升级后会撤销这些旧会话；一次性新密码从受限的服务启动日志取得，首次登录仍要求改密。学生登记现在需要可用 Redis；共享网络可调整 `.env.example` 中的限流参数。

代码和测试保留在工作区，未提交、未部署，也没有修改真实生产数据。
